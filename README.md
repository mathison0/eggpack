## 게임 소개

### 게임 시작

[로비.mp4](attachment:f948c4df-be27-4b0a-bba3-8a688485d14f:로비.mp4)

1. 게임 시작을 누른다.
2. 로비를 생성한다. (혹은 친구가 생성해주길 기다린다.)
3. 친구한테 로비 코드를 알려준다.
4. 로비 코드를 받아 입력 한 후, ‘코드로 참여’를 누른다.
5. 호스트가 게임을 시작한다.

## 개발 과정

### 실시간 연동

![image.png](attachment:7a900479-47c3-4b06-a708-670ae8e2aeb4:image.png)

- WebRTC(Web Real-Time Communication)는 별도의 프로그램이나 플러그인 설치 없이 클라이언트 간에 직접 실시간 통신을 가능하게 하는 P2P 기술입니다. 중앙 서버를 거치지 않고 일대일로 통신하여 데이터 전송 지연 시간을 크게 줄였습니다.
- 최초의 연결을 위한 시그널링 서버로 AWS의 EC2 서비스를 활용하였습니다.
- Godot Engine에서의 자세한 통신 방법은 https://docs.godotengine.org/en/4.4/tutorials/networking/webrtc.html 에서 확인하실 수 있습니다.

### 에셋 제작

![image.png](attachment:cf2d1172-40a4-4b4c-bbed-af940a288333:image.png)

- Aseprite를 사용해 모든 맵타일 에셋을 만들었습니다.
- 애니메이션의 경우 7~8프레임의 에셋을 찍어 구현했습니다.
- 여러 타일이 중간에 끊기지 않고 자연스럽게 보이도록 하기 위해, 한 가지 타일에도 여러 종류의 에셋을 만들었습니다.

![image.png](attachment:3b05d595-fd1b-4f9a-99be-908109ad517b:image.png)

![image.png](attachment:d715bf56-f16b-4338-b88d-48164c802727:image.png)

- 상태이상, 아이템, 오브젝트들의 에셋 또한 자체 제작하였습니다.

## 후기

**김지민:** 평소 항아리류 게임을 해보며 고통을 받았던 제겐 꿈이 하나 있었습니다. 제가 직접 항아리류 게임을 만들어 플레이어들에게 즐거움을 선사해주는 것이었죠. 다양한 도트 에셋들을 직접 만들며, 맵을 만드는 작업이 매우 재밌었습니다. 특히 흥미로웠던 것은, 반응속도가 중요한 게임의 멀티플레이 구현을 위해 WebRTC를 활용한 실시간 2인 게임을 구현하는 것이었습니다. 자료가 많이 없어 영어로 된 2시간 짜리 영상을 보며 2일 동안 노력했던 것 같네요. 세영이와 함께한 시간이 정말 즐거웠습니다!

**박세영**: 기획부터 끝까지 게임을 개발한 경험은 이번이 처음이었는데, 지민이 덕에 끝까지 잘 마무리 할 수 있었습니다. 사용해보지 않았던 Godot 엔진도 이용해보고 이 과정에서 게임 엔진 자체에 익숙해지는 시간이었습니다. 물어볼때마다 친절히 알려준 지민 선생님께 압도적 감사의 인사를 전합니다. 즐거웠다!!

다른 사람들이 우리 게임을 플레이하고 더욱 가까워지는 시간을 가졌으면 좋겠습니다.
